## Product Information

### Product Name
```
HoneyConvert
```

### Tagline (60 characters max)
```
Free HEIC to PNG, JPEG, WebP converter for iPhone photos
```

### Short Description (260 characters)
```
Convert your iPhone photos instantly! HoneyConvert is a free, privacy-first tool that transforms HEIC/HEIF images to PNG, JPEG, or WebP. Features batch conversion, multiple size options, and no registration required. Your photos are deleted immediately after conversion.
```

### Full Description
```
## The Problem
Ever tried sharing an iPhone photo with someone on Windows? Or uploading one to a website that doesn't accept HEIC? You're not alone. Apple's HEIC format saves storage space but creates compatibility headaches.

## The Solution
HoneyConvert is a free, instant HEIC converter that just works:

**Multiple Output Formats**
- PNG: Lossless quality, perfect for graphics
- JPEG: Smaller files, great for sharing photos
- WebP: Modern format, best of both worlds

**Size Options**
- Original (100%)
- Large (75%)
- Medium (50%)
- Small (25%)

**Privacy First**
Your photos are processed securely and deleted immediately after conversion. No accounts, no tracking, no nonsense.

**Batch Conversion**
Convert multiple files at once. Download as a ZIP or individually.

## Why We Built This
We were tired of sketchy converter sites with ads everywhere and confusing interfaces. HoneyConvert is the tool we wanted to exist: fast, free, clean, and private.

## Tech Stack
- Python/Flask backend
- Pillow for image processing
- Vanilla JavaScript frontend
- No frameworks, no bloat

## Try It Now
Drop your HEIC files and convert in seconds. No registration required.
```

## Maker Interview Questions (Prepare answers)

**Q: What inspired you to build HoneyConvert?**
```
Every time I tried to share iPhone photos with Windows users, I had to hunt for a converter. The existing options were either full of ads, required registration, or felt sketchy with unclear privacy practices. I wanted something simple: drag, convert, done.
```

**Q: How is HoneyConvert different from other converters?**
```
Three main differences:
1. Privacy-first: Files are deleted immediately, not stored
2. No registration: Just start converting
3. Multiple formats: PNG, JPEG, and WebP output options
Plus it's completely free with no hidden limits.
```

**Q: What's your tech stack?**
```
Python/Flask backend with Pillow for image processing. Vanilla JavaScript frontend - no heavy frameworks. Hosted on Railway. Kept it simple and fast.
```

**Q: What's on your roadmap?**
```
Short term: Advanced editing options like crop and rotate
Medium term: Mobile apps for iOS and Android
Long term: Developer API for integrations
```
